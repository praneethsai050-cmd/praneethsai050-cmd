## 🛡️ Flagship Project: Satyameva Aegis

> **Decentralized Academic & Identity Credentialing System with Zero Gas Fees**  
> *Selected for RIDEHACK'26 Grand Finals (Team ID: 10) & Smart India Hackathon 2026 (Team CYPHER-X)*

```
[ University Registrar ]  ──►  [ Custom PoW Blockchain Engine ]  ──►  [ Permanent QR / Hash Ledger ]
                                      ▲                 │
                                      │                 ▼
[ OpenCV 128D Face-Lock ] ────────────┴───── [ Tamper Heatmap & Gemini OCR ] ──► [ Instant Verification ]
```

| Metric / Attribute | Technical Specification |
| :--- | :--- |
| **Consensus Engine** | Custom Python SHA-256 Proof-of-Work (PoW) ledger running without third-party gas fees or network volatility |
| **Biometric Layer** | 128-dimensional OpenCV face-embeddings bound mathematically with student cryptographic records |
| **Forensic Tamper Detection** | PIL differential pixel heatmapping to flag cloned, forged, or edited credential documents |
| **Document OCR** | Multimodal Gemini 2.0 Flash engine for high-throughput, structured marksheet data extraction |
| **Benchmarked Impact** | **92% verification latency drop** (from 60+ min to <5 min) & **₹0 cost** to students and verifiers |
| **Commercial Model** | B2B Campus SaaS (`₹1.5L/year`) + Pay-per-verify corporate API (`₹25/query`) |
| **Pitch Presentation** | 📺 [Watch Official SIH Presentation on YouTube](https://youtu.be/Uu-bOJTZrFY) |
